Браузерные конструкторы: Bolt / Replit / Lovable

Экосистема · ≈ 4 мин

Что это

AI-конструкторы в браузере. Без установки. Без терминала. Открыл вкладку, написал «сделай мне сайт» — получил работающее приложение с базой и публичной ссылкой за 20 минут.

Это «Claude Code + хостинг + база + деплой» в одном окне для тех, кому не хочется заморачиваться с инфраструктурой.

Когда брать конструктор, а не Claude Code

🟢 Конструктор лучше:
- Быстрый прототип за 20 минут
- Не хочется поднимать локальное окружение
- Делишься ссылкой нетехнической команде
- Простой CRUD, лендинг, форма
- Разовая поделка

🔴 Claude Code лучше:
- Сложная задача, упрёшься в ограничения
- Нужна гибкость со стеком
- Нестандартное API / интеграция
- Проект растёт — переехать на свой код потом сложно

Одна задача — два подхода

«Лендинг для онлайн-курса с формой записи в Google Sheets»:

  • Через Claude Code: ~1 час. Свой код, бесплатный хостинг, можешь править что угодно.
  • Через Lovable: ~20 минут. Ноль настройки. Но $25/мес и привязка к платформе.

Обе работают. Выбор зависит от того, сколько ты планируешь жить с проектом.
