# Хранение данных и публикация

_Экосистема · ≈ 5 мин_

## Зачем

Сделал прототип на ноутбуке, открывается на `localhost:3000`. Хочешь показать клиенту / коллегам. Возникает: **где хранить данные** и **где разместить, чтобы открывалось по ссылке**.

Этот блок — карта вариантов. Чтобы знать, что куда подходит.

## Где хранить данные

| Сколько и как | Решение |
|---|---|
| Мало, не меняется (список курсов на лендинге) | Прямо в коде или JSON-файл |
| Мало, меняется (форма записи, заявки) | Google Sheets через API |
| Много или сложные запросы | База данных |

**База:** для большинства задач — PostgreSQL.

**Где её разместить:**
- **[Supabase](https://supabase.com)** — PostgreSQL + админка + авторизация + файлы. Бесплатный тариф достаточен для прототипа. Самый popular.
- **[Neon](https://neon.tech)** — PostgreSQL без лишнего. Дешевле при росте.
- **[Railway](https://railway.app) / [Render](https://render.com)** — БД + хостинг бэкенда одним пакетом.

## Как опубликовать

**Лендинг / статика (HTML, Next.js):**
- **[Cloudflare Pages](https://pages.cloudflare.com)** — бесплатно неограниченно, авто-деплой из GitHub
- **[Vercel](https://vercel.com)** — самый простой деплой Next.js / React
- **[GitHub Pages](https://pages.github.com)** — бесплатно из любого репо, только статика

**Приложение с бэкендом (Node, Python, Go):**
- **[Railway](https://railway.app)** — деплой кнопкой, БД рядом, от ~$5/мес
- **[Render](https://render.com)** — похож на Railway, есть free tier
- **[Fly.io](https://fly.io)** — глобальный деплой, мощнее, сложнее

**Telegram-боты, фоновые задачи:** Render Background Workers — проще всего на старте.

## Своё доменное имя

Хочешь не `проект.vercel.app`, а `мойсайт.ру`:

- **Где купить:** [reg.ru](https://reg.ru) (российские, .ru от 200₽/год) · [namecheap.com](https://namecheap.com) (международные, .com от $10/год)
- **Как привязать:** в настройках домена меняешь NS или DNS-записи на те, что даёт хостинг. Через 5 минут — 24 часа открывается.

## Секреты — в переменные окружения

**API-ключи и пароли в коде = беда.**

- В `.env`-файле (он в `.gitignore`, не коммитится в git)
- На хостинге — в переменных окружения (Vercel/Cloudflare/Railway всё это умеют)
- Засунул ключ в публичный репо — **сразу иди и отзывай ключ в сервисе**. История git хранит всё.

## Что выбрать на старте

| Задача | Решение |
|---|---|
| Лендинг / прототип фронта | Cloudflare Pages |
| Приложение с базой | Vercel + Supabase |
| Telegram-бот | Render |

Сложнее не нужно. Если упрёшься — Claude Code сам подскажет.
