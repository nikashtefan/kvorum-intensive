Содержимое 12 старых блоков

Тексты в новых файлах извлечены из текущего LMS (через RSC payload /course/<slug>). Это точная копия того, что сейчас лежит в LMS — ничего не дописывал. Если в LMS будут правки текста — их можно сразу вносить, не сверяясь с этими файлами.

В файлах сохранены:
- заголовки (H1, H2, H3)
- списки и нумерация
- блоки кода
- таблицы
- картинки/диаграммы (как ![alt](path))
- чек-листы готовности (в конце каждого блока)

Чего нет в файлах: компонентов LMS (кнопки «отметить пройденным», интерактивные чек-листы) — это техническая обвязка LMS, на уровне контента ничего не теряется.

Метаданные блоков

В каждом файле под H1 курсивом стоит мета вида _Основа · ≈ 8 мин_. Это:
- категория (Старт / Основа / Методика / Практика / Справочник / Экосистема / После интенсива)
- примерное время на чтение

Можно использовать для отображения в карточке блока.

Технические детали извлечения

Содержимое существующих блоков получено через:

curl https://lms.kvorum-edu.ru/course/<slug> -H "Cookie: kvorum_session=<JWT>"

Затем из HTML вытащен RSC payload и собраны все markdown-фрагменты по каждому блоку.

Извлечённые «сырые» файлы лежат в _extracted/ — можно сравнить с финальными файлами в новой структуре, разницы нет (только переименование).
