# Типичные проблемы и решения

_Справочник · ≈ 7 мин_

## Установка и запуск

### «command not found: claude»

PATH не обновился. Самые частые причины:
- Не закрыл и не открыл терминал заново — закрой все, открой новый.
- На Windows папка `~/.local/bin` не в PATH (см. блок starter-install).
- На macOS / Linux добавь в `~/.zshrc` или `~/.bashrc`:

  ```bash
  export PATH="$HOME/.local/bin:$PATH"
  ```

  Затем `source ~/.zshrc` (или `source ~/.bashrc`).

### Установщик зависает или возвращает HTML

Сеть блокирует серверы Anthropic — корпоративный фаервол, провайдер. Решения:
- Попробуй из дома, не из офиса.
- Используй мобильный интернет как тест.
- Скачай скрипт отдельно (`curl -O https://claude.ai/install.sh`), посмотри что внутри, запусти руками.

### При первом запуске бесконечно крутит «Authenticating»

- Проверь, что в браузере точно нажал Continue / Allow.
- Закрой Claude Code (`/exit` или Ctrl+C), запусти заново.
- Если повторяется — `claude doctor` (диагностика).

### «Permission denied» при создании файлов

Запускаешь не из той папки, где есть права на запись. Проверь:

```bash
pwd        # где ты
ls -la     # есть ли права
```

Перейди в `~/Documents` или другую свою папку.

### Claude использует не ту модель

По умолчанию Sonnet. Чтобы переключить:

```
/model
```

Выбери Opus для сложных задач или Haiku для простых быстрых.

### Лимит закончился

Pro имеет лимиты. Когда упрёшься — Claude напишет, сколько до сброса (обычно несколько часов). Если нужны бо́льшие — апгрейд до Max.

## Оплата

### «Card declined» / «Payment failed»

В 80% случаев — адрес для оплаты. На виртуальной карте он должен совпадать с тем, что показывает сервис карт (испанский / американский / т.п.). НЕ российский.

Если адрес правильный:
- Проверь срок и CVV. У некоторых виртуальных карт CVV меняется при пополнении.
- Проверь баланс — должно хватить на $20 + комиссию + запас на проверочные списания.
- Попробуй из другого браузера или в режиме инкогнито.

### «Списало, но Pro не активировался»

Подожди 5–10 минут, обнови страницу. Если за час не активировался — пиши в поддержку Anthropic с номером транзакции.

### Посредник просит доступ к аккаунту

Норма для процедуры, но:
- Используй временный пароль, который сразу поменяешь.
- Проверь, что двухфакторная защита (2FA) не сбита после.
- Не давай доступ, если в чатах с Claude чувствительная информация.

## Поведение агента

### Claude игнорирует CLAUDE.md

Проверь:
- Файл точно называется `CLAUDE.md` (регистр важен на Linux/macOS).
- Файл лежит в корне той папки, откуда запущен `claude`.
- Файл меньше 200 строк (большие файлы Claude может «срезать»).
- В сессии не было `/clear` после открытия — на самом деле `/clear` оставляет CLAUDE.md, но проверь.

Тест: спроси «какие правила ты сейчас знаешь по этому проекту?» — если перечисляет твои — всё работает.

### Claude уходит в бесконечный цикл правок

Сигналы:
- Третий раз предлагает то же.
- Каждый «фикс» ломает другое.
- Ошибки накапливаются.

Что делать:
- `/clear` или новая вкладка.
- Опиши задачу заново, с актуальным состоянием.
- Покажи текущий diff и текущую ошибку как новую задачу.
- Если задача большая — разбей.

### Claude правит файлы, которые ты не просил

Проверь diff построчно. Если правки не нужны — попроси откатить:

```
В этой задаче ты поменял файл X. Я не просил его трогать.
Откати изменения в X. Остальное оставь как есть.
```

В следующий раз в брифе явно укажи: «можно менять только A и B».

### Claude утверждает, что работает то, что не работает

Классика «лучшая практика», «обычно работает», «должно работать». Не верь — запусти и проверь. Если запуск падает — покажи ошибку.

### Claude молчит / отвечает обрывками

Скорее всего — упёрся в лимит контекста. Проверь:

```
/context
```

Если близко к лимиту:
- `/compact` — сжать контекст с сохранением сути.
- `/clear` — начать заново (потеряешь историю).
- Перенеси задачу в новую вкладку.

### Claude не видит файл, на который ты ссылаешься

Проверь:
- Путь относительный или абсолютный — Claude любит абсолютные.
- Файл существует (`ls <путь>`).
- Файл не в `.gitignore` или другой папке-исключении.

Покажи явно: `прочитай файл /полный/путь/к/файлу.ts`.

## MCP

### MCP-сервер «не отвечает»

- Проверь, что сервер запущен (для локальных серверов).
- Проверь авторизацию: возможно, токен истёк — переподключи коннектор.
- В Claude Code: `claude mcp list` показывает подключённые серверы и их статус.

### MCP вернул больше прав, чем ожидал

Заходи в настройки исходного сервиса (Notion, Drive, Linear) → раздел Connections / Integrations / Apps → найди Claude → отзови или сузь права. После — переподключи в Claude.

### Claude не понимает, какой MCP использовать

Назови сервис явно: «найди в **Notion**...», «создай задачу в **Linear**...». Без явного указания Claude может выбрать не тот источник.

## Когда звать в чат потока

Не пытайся ломать дальше, если:
- Установка тянется больше часа.
- Получаешь одну и ту же ошибку 3 раза подряд после разных попыток.
- Проблема с оплатой (списало, но не активировалось — есть актуальный список рабочих способов).

В сообщении: ОС, версия, шаг, точный текст ошибки (скрин/копипаст).
