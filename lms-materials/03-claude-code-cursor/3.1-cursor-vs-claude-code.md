# Cursor vs Claude Code: что когда использовать

_Основа · ≈ 4 мин_

## Зачем

На интенсиве работаем в связке Cursor + Claude Code. Это не «или-или», а два инструмента под разные задачи.

## Что есть что

**Cursor** — редактор кода (форк VS Code) с встроенным AI. Ты ведёшь, AI помогает: автокомплит, правки с предпросмотром, чат сбоку. Видишь каждое изменение.

**Claude Code** — CLI-агент от Anthropic. Запускается командой `claude` в терминале. Ты ставишь задачу — агент сам читает файлы, пишет код, запускает команды, проверяет, исправляет. Видишь финальный diff.

В одной фразе: **Cursor — ассистент при тебе. Claude Code — подрядчик, которому делегируешь.**

## Когда что брать

| Cursor | Claude Code |
|---|---|
| Ты ведёшь, AI помогает | AI ведёт, ты проверяешь |
| Малые точечные правки | Многофайловые задачи |
| Понять чужой код | «Сделай Х под ключ» |
| Автокомплит во время печати | Запуск тестов / команд / деплой |

**🟢 Cursor:** правка одного файла · понять чужой код · точечная фича.
**🟢 Claude Code:** многофайловая задача · «сделай Х под ключ» · черновик целой фичи.

## Они работают вместе

В реальной работе переключаешься между ними весь день:

1. Открыл проект в **Cursor**
2. Большая задача → зовёшь **Claude Code в терминале** (`claude`)
3. Возвращаешься в Cursor — смотришь diff, правишь руками одну деталь
4. Опять зовёшь Claude Code на следующую задачу

Cursor визуализирует. Claude Code делает. Связка покрывает весь спектр.

## CLAUDE.md — один файл для обоих

`CLAUDE.md` (см. блок **3.2**) — память и инструкции для AI. Читается обоими: и Claude Code, и Cursor. Пишешь один файл — оба инструмента видят твой контекст.
