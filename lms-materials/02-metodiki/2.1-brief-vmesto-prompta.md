# Бриф вместо промпта

_Основа · ≈ 8 мин_

## Зачем этот блок

90% людей пишут промпты так: «сделай мне Х». Получают мусор, винят AI. На самом деле AI получил 5% контекста и догадывался об остальном.

Профессиональная работа с Claude — это не «писать промпты», а передавать бриф. Тот же бриф, который продакт пишет дизайнеру или разработчику. Просто адресат — модель.

После этого блока ты перестанешь общаться с Claude как с гуглом. Начнёшь — как с подрядчиком.

## Антипаттерн: промпт-однострочник

```
Сделай мне лендинг для кофейни.
```

Что произойдёт: Claude сделает условный лендинг. Скорее всего, тёмный с эспрессо-эстетикой. Скорее всего, на английском. Скорее всего, с «Subscribe to our newsletter». Это будет лендинг для средней кофейни в среднем городе мира, а не для твоей.

Потом потратишь 6 итераций на «нет, не такой», «убери ньюслеттер», «сделай по-русски», «у меня не эспрессо, у меня спешелти». В каждой итерации Claude теряет часть предыдущего контекста.

## Правильный подход: бриф из 5 слотов

Каждая задача = заполненный шаблон с пятью слотами:

1. **Контекст** — что вообще происходит, кто я, для кого делаю
2. **Роль** — кем должен быть Claude в этой задаче
3. **Задача** — что конкретно нужно сделать (ровно одна)
4. **Ограничения** — что нельзя / что обязательно
5. **Критерии приёмки** — как пойму, что получилось

Тот же кейс через бриф:

```
КОНТЕКСТ
Я владелец спешелти-кофейни в Питере на 12 посадочных мест. ЦА — местные
25-40 лет, ходят за кофе по дороге на работу и в выходные с ноутбуком.
Главная боль — люди не знают, что мы обжариваем зерно сами, и сравнивают
нас по цене со Старбаксом.

РОЛЬ
Веб-дизайнер с фокусом на конверсию для малого бизнеса в HoReCa.

ЗАДАЧА
Сделай одностраничный лендинг для кофейни. Цель — чтобы человек,
попавший с поиска "спешелти кофе [район]", за 30 секунд понял
что мы и захотел зайти.

ОГРАНИЧЕНИЯ
- Только русский язык
- Без формы подписки на новостник
- Светлая тема, не тёмная
- Без градиентов и пиксельных иллюстраций (не «генеричный AI-сайт»)
- Контент-блоки: кто мы, наш подход к зерну, меню (3 топовых позиции),
  где найти, инстаграм
- HTML + CSS, без фреймворков, в одном файле

КРИТЕРИИ ПРИЁМКИ
- Лендинг открывается одним index.html
- На мобильном без горизонтального скролла
- В первом экране: что это, где, чем отличается
- Меню — список с ценами, не карточки
```

Теперь Claude не угадывает. Он исполняет.

## Шаблон брифа

```
КОНТЕКСТ
[Кто я. Для кого делаю. Какую боль решаю. 2-4 предложения.]

РОЛЬ
[Кем должен быть Claude. «Senior backend-инженер с опытом в...»,
«PM с опытом запуска B2C-продуктов».]

ЗАДАЧА
[Одна задача. Если две — это два брифа.]

ОГРАНИЧЕНИЯ
- [Что нельзя]
- [Что обязательно]
- [Технологии / язык / тон / формат]

КРИТЕРИИ ПРИЁМКИ
- [Как пойму, что результат хороший]
- [Что должно работать]
- [Чего не должно быть]
```

## Где это бьёт сильнее всего

- **Кодовые задачи:** не указал стек, фреймворк, версию — Claude угадает. Угадывание = переделка.
- **Тексты:** без указания тона и аудитории — получишь «AI-стиль». Все жалуются на этот стиль, но в брифе никто не пишет «не пиши в стиле LinkedIn-постов».
- **Аналитика:** без указания формата (таблица / абзац / JSON) — получишь длинный абзац, который потом резать.

## Чек-лист «бриф готов»


Если 5+ галочек — отправляй. Меньше — дописывай.

## Практика к вебинару

1. Возьми реальную задачу с прошлой недели, где получил «не то».
2. Восстанови, как тогда сформулировал.
3. Перепиши через шаблон-бриф.
4. Запусти оба варианта в новых чатах. Сравни результат.

На вебинаре разберём 3–4 случая в группе.

## Чек-лист готовности

- [ ] Контекст ≤ 5–6 строк, есть «кто я и для кого»
- [ ] Роль конкретная (не «эксперт», а «эксперт в Х»)
- [ ] Задача одна
- [ ] Минимум 3 ограничения
- [ ] Указан формат вывода (файл / список / абзац / код)
- [ ] Минимум 2 критерия приёмки
- [ ] Если код — стек/версия; если текст — тон/аудитория/длина
