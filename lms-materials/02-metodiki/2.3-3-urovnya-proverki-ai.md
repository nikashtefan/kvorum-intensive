# 3 уровня проверки результата AI

_Основа · ≈ 5 мин_

## Зачем

AI часто отвечает уверенно — и часто неправильно. Самая опасная зона — когда ответ выглядит профессионально (цифры на месте, ссылки красивые, формулировки уверенные), а половина — выдумка.

Проверка — не паранойя. Часть workflow, как тестирование в коде.

## Уровень 1. Гигиена — встраивай всегда

Ловит 60-70% мелких косяков. Дописывай в каждый промпт.

**Разреши не знать:**
```
Если на каком-то шаге не уверен — скажи прямо «не знаю»,
не додумывай.
```

**Уровень уверенности:**
```
После ответа добавь строку: Уверенность X/10. Объясни почему.
```

**Цитируй источник** (когда работаешь с документом):
```
Сначала приведи дословную цитату, потом сделай вывод.
```

## Уровень 2. Углублённая — для важных решений

Деньги, время команды, тексты для клиентов. +5-10 минут.

**Chain-of-Verification:**
```
Составь 5 ключевых фактов из ответа. По каждому ответь:
откуда я это знаю · может ли быть иначе · насколько уверен.
```

**Адвокат дьявола:**
```
Найди 3-5 слабых мест в этом ответе. С чем можно не согласиться?
```

**Пошаговая логика:**
```
Прежде чем дать ответ — опиши шаги рассуждения. Каждый шаг
отдельной строкой. В конце — вывод.
```

## Уровень 3. Внешняя — для критичных

Юр. документ, мед. совет, факты для публикации, важная аналитика.

⚠️ **AI, проверяющий сам себя — работает ограниченно.** Если модель ошиблась в первый раз, она с большой вероятностью повторит ту же ошибку при self-check. Уровни 1 и 2 ловят явные косяки, но не системные галлюцинации.

**Второй AI:**
```
Вот ответ от Claude по моему вопросу: [...]
Найди фактические ошибки, неточности, пропущенный контекст.
```

**Чек-лист по фактам:** цифры в первоисточнике? · цитаты существуют? · ссылки открываются и подтверждают? · «всегда / никогда / все» корректны? · упущенный контекст?

**Проверка ссылок** (самая частая дыра): проси модель давать источники в формате `название · автор · год · URL · что говорит по теме`. Открой 2-3, проверь. Хоть одна не существует — отбрасывай весь список.

## Какой уровень выбирать

| Задача | Уровень |
|---|---|
| Брейнсторм, идеи, варианты | 1 |
| Черновик письма / соцсетей | 1 |
| Код, который сам запустишь | 1 |
| Обоснование решения для команды | 2 |
| Стратегия, аналитика, цифры для презентации | 2 |
| Юр / мед / фин документ | 3 |
| Публикация в СМИ | 3 |
| Решение, которое нельзя откатить | 3 |

Уровень 1 кажется тривиальным — поэтому его пропускают. Именно из-за этого получают «правдоподобный мусор». **Привычка: одна фраза из уровня 1 в каждом промпте, где важна точность.**

## Чек-лист готовности

- [ ] Помню три приёма уровня 1: разреши не знать · уверенность 0-10 · цитируй источник
- [ ] Хотя бы один встроил в свой стандартный промпт
- [ ] Понимаю: для уровня 3 нужен второй источник или человек, не self-check
- [ ] Был хотя бы один случай, когда AI признался «не знаю» благодаря моей фразе
