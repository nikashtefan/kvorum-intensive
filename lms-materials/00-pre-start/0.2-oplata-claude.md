## Рекомендованная цепочка: США

Самая стабильная связка на 2026 — **полностью США**:
- IP под VPN — США
- Виртуальная карта с BIN банка США
- SMS-номер США
- Адрес для оплаты — США

Альтернатива целиком — **Великобритания**. Турция, Казахстан, Армения сейчас работают хуже: у местных финтех-карт BIN нестабильный, и адрес владельца карты часто не совпадает с адресом для оплаты.

### Звено 1. VPN — AmneziaVPN на своём VPS

![amnezia.org — open-source VPN, ставится на свой VPS](/screens/payment-amneziavpn.png)

**[AmneziaVPN](https://amnezia.org/)** — клиент с открытым кодом, разворачивается на твой собственный VPS (виртуальный сервер) в США. Главное преимущество — **уникальный «чистый» IP**, который не делится с тысячами других пользователей. Именно общие IP коммерческих VPN — частая причина массовых блокировок: один аккаунт попался — заблокировали весь диапазон IP.

Как поднять:
1. Купи VPS в США за $5/мес: [DigitalOcean](https://www.digitalocean.com/), [Vultr](https://www.vultr.com/), [Hetzner](https://www.hetzner.com/) (Ashburn регион).
2. Скачай Amnezia с [amnezia.org/downloads](https://amnezia.org/downloads).
3. В приложении введи IP сервера и SSH-ключ — Amnezia сама развернёт VPN-сервер.
4. Подключайся как обычный VPN-клиент.

**Альтернатива (если поднять свой сервер некому):** платные коммерческие VPN с менее засвеченным набором IP — Mullvad, IVPN, ProtonVPN. Выбирай страну, в которой набор IP меньше. NordVPN и ExpressVPN — риск выше, их IP Anthropic уже знает.


### Звено 2. Виртуальная карта с US BIN

Решает не страна выпуска, а **BIN** (первые 6 цифр номера карты). У Anthropic есть свой список разрешённых BIN-ов, и не каждый BIN проходит даже у формально «правильной» страны.

Работают на 2026:
- **[Halocard](https://halocard.co/virtual-cards/anthropic-claude)** — Visa с американским BIN, прицельно для Anthropic.
- **[Heleket](https://heleket.com/)** — проходит подтверждение 3D-Secure без сюрпризов.
- **[Wanttopay](https://wanttopay.io/)** — карты с американскими реквизитами через Telegram-бот.
- **[Buvei](https://buvei.com/)** — обзоры BIN-ов и виртуальных карт «как они устроены изнутри».

НЕ работают / блокируют:
- **Pyypl** — массовые отказы Anthropic в 2025-2026, исключён из рекомендаций.
- **Wise / Revolut** — формально работают, но при их проверке владельца (KYC) адрес часто не совпадает со страной аккаунта → блокировка.
- Российские карты, **МТС-подписки**, ЮMoney — не принимаются.

Шаги:
1. Зарегистрируйся в одном из сервисов выше. Пройди проверку личности (KYC), если требуется.
2. Пополни через крипту или СБП-посредников. Положи минимум $30 (Pro $20 + комиссия 5–15% + запас).
3. **Запиши адрес для оплаты из приложения карты** — это адрес страны выпуска карты, не российский. Самая частая причина отказа — указали российский адрес.

### Звено 3. SMS-номер США

Anthropic принимает не все коды стран. Безопасные — **США, UK, Нидерланды, Канада**.

- **[5sim.net](https://5sim.net/products/claudeai)** — самый широкий ассортимент, прицельные номера под Claude.
- **[sms-activate](https://sms-activate.io/)** — популярный в СНГ.
- **[GrizzlySMS](https://grizzlysms.com/claude)** — есть отдельная категория Claude.
- **[smspva](https://smspva.com/service/214-claude)** — альтернатива.

Один номер — один аккаунт. Не переиспользовать. Стоимость номера США под Claude — $0.5–2.

### Звено 4. Адрес для оплаты — США

Можно взять любой реальный американский адрес из открытых источников: адрес отеля, библиотеки, любого публичного здания. Адрес должен **существовать** и **соответствовать ZIP-коду** (почтовому индексу США). Anthropic проверяет это автоматически — система AVS сверяет адрес с базой банка.

## Минимальный сценарий «с нуля до Pro»

1. **Подними AmneziaVPN на американском сервере** ($5/мес).
2. **Заведи виртуальную карту с американским BIN** (Halocard или аналог), пополни на $25-30.
3. **Купи SMS-номер США** на 5sim ($0.5-2).
4. **Под VPN** зарегистрируй аккаунт на claude.ai с американским номером и адресом.
5. **Не выходя из-под VPN** оплати Claude Pro на [claude.ai/upgrade](https://claude.ai/upgrade).
6. **Никогда** не заходи с российского IP — даже один такой заход может сжечь аккаунт.

## Что делать, если оплата не проходит

1. Проверь, что адрес для оплаты — американский (не российский).
2. Проверь, что страна IP под VPN = страна BIN карты = страна номера = страна адреса.
3. Подожди 10 минут — Anthropic иногда тормозит с активацией.
4. Попробуй другую виртуальную карту (BIN мог попасть в чёрный список).
5. Если аккаунт заблокирован — порядок обжалования описан на [photonpay.com](https://www.photonpay.com/hk/blog/article/why-your-claude-account-is-suspended), [laozhang.ai](https://blog.laozhang.ai/en/posts/claude-code-max-recharge-account-banned).

## Что НЕ делать

- **Не покупать готовые аккаунты** Claude Pro на форумах — отваливаются через неделю-две.
- **Не использовать Cloudflare WARP** — Anthropic фильтрует его IP.
- **Не смешивать страны** в цепочке — главная причина блокировок.
- **Не заходить с российского IP** ни при каких обстоятельствах.
- **Не использовать массовый коммерческий VPN с засвеченными IP** (NordVPN, ExpressVPN на популярных серверах).
- **Не платить криптой через серые сервисы** — риск потерять и деньги, и аккаунт.
