# Ссылки и дополнительные материалы

_Справочник · ≈ 5 мин_

## Безопасность и секреты

Минимум, который должен знать любой пользователь Claude Code.

### Что нельзя делать никогда

- Не клади API-ключи и пароли в CLAUDE.md. Они уходят в контекст модели. Используй `.env`.
- Не клади секреты в код, который Claude видит. Через переменные окружения.
- Не давай Claude доступ к продовой БД на «потести». Только staging / dev / read-only.
- Не подключай личный Notion с приватной информацией к рабочим задачам. Разделяй контуры.

### .env и .gitignore

В корне проекта — файл `.env`:

```
ANTHROPIC_API_KEY=sk-...
SUPABASE_URL=https://...
SUPABASE_KEY=...
```

В `.gitignore` обязательно:

```
.env
.env.local
.env.*.local
```

Проверь руками: `git status` — `.env` не должен светиться.

### Что делать, если ключ утёк

1. Немедленно отзови в консоли провайдера (Anthropic Console / Supabase / etc.).
2. Сгенерируй новый.
3. Если ключ ушёл в публичный репозиторий — мало просто удалить файл, нужно почистить историю (`git filter-branch` или BFG).
4. Проверь биллинг провайдера на следующий день.

### Права при подключении MCP

Когда подключаешь Notion / Drive / etc., тебе дают выбор: к каким страницам / папкам открыть доступ. Дай минимум, который нужен задаче. Не «всё рабочее пространство», а «папка проекта Х».

Сужать права сложнее, чем расширять.

## Когда какой инструмент

### Claude.ai (веб)

**Когда:** текстовые задачи (анализ, написание, разбор), быстрые консультации, Projects с knowledge файлами, нет терминала под рукой.

**Когда нет:** работа с локальными файлами проекта, многошаговая работа с кодом, skills и MCP по полной.

### Claude Code (терминал)

**Когда:** локальный проект (файлы, код, репозиторий), многошаговые задачи с автоматизацией, skills и MCP в полной форме, AI делает руками а не подсказывает.

**Когда нет:** не открываешь терминал — начни с Claude.ai. Однострочные вопросы здесь — из пушки по воробьям.

### Cursor / VS Code Extension

**Когда:** AI внутри редактора для дополнения кода построчно, ты программист и пишешь код руками.

**Когда нет:** не пишешь код руками — не надо. Если нужна агентская работа — Claude Code лучше.

### Сравнение в таблице

| Задача | Лучший инструмент |
|---|---|
| Разбор интервью / документа | Claude.ai (Projects) |
| Поправить файл в проекте | Claude Code |
| Многофайловая фича | Claude Code |
| Автокомплит при ручном кодинге | Cursor |
| Подключение к Notion/Linear | Claude Code или Claude Desktop с MCP |
| Сборка прототипа за вечер | Claude Code |
| Быстрый вопрос, не связанный с проектом | Claude.ai |

## Привычки и рабочий процесс

### Утренние

- **Дайджест.** Один шаблон промпта, одно касание Claude — обзор задач, писем, новостей по твоим темам. Через MCP — 30 секунд.
- **Записывать контекст в CLAUDE.md.** Решение за вчера — одной строкой в раздел «текущий фокус». Завтра Claude помнит.

### Дневные

- **Бриф вместо промпта — всегда.** Любая задача дольше 2 минут — через шаблон. Автоматическим становится за 2–3 недели.
- **План-режим на сложной задаче.** Не ленись — сэкономишь час отладки.
- **Не открывать 10 чатов на одну тему.** Один проект — одна папка с CLAUDE.md.

### Недельные

- **Разбор того, что застряло.** Раз в неделю — список задач, где «AI не помог». Скорее всего, дело в брифе. Возьми 1–2 худших, перепиши, посмотри разницу.
- **Доращивание skills.** Задача повторилась 3 раза за неделю — кандидат в skill.
- **Чистка контекста.** Старые CLAUDE.md актуализировать. Неиспользуемые skills — удалять.

### Антипаттерны процесса

- «AI на всё подряд». На задачах в 5 минут руками — не зови AI. Не окупается.
- «Один большой чат на всё». Контекст забивается, качество падает.
- «Сделал, не понял — закрыл». Если работает, но не понимаешь — это технический долг, который вернётся.
- «Не использую план-режим, потому что долго». На отладке теряешь в 5 раз больше.

## Финальный чек-лист интенсива


Если 80% галочек — интенсив прошёл успешно. Если меньше — на разборе домашки добиваем.

## После интенсива

- Поток продолжает поддержку в чате 4 недели.
- Live-разборы домашки — раз в неделю.
- Обновления конспекта (всегда читай актуальные блоки на платформе, а не локальный кэш).
